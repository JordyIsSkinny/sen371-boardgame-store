# Design System — Tokens

Source of truth for the values in `client/src/index.css`'s `@theme` block
(Tailwind v4, CSS-first — there is no `tailwind.config.js`). Committed here
so the values are checkable against something, not just the token file's own
comments. Where a value came from the Figma design system export directly,
it's marked **given**; where it was generated to fill a gap Figma didn't
specify, it's marked **generated**, with the method.

## Colour

### Primary — indigo

| Token | Hex | Source |
|---|---|---|
| `primary-100` | `#E6E4F5` | given |
| `primary-200` | `#B7B2DE` | generated — HSL midpoint of 100/300 |
| `primary-300` | `#8A83C4` | given |
| `primary-400` | `#6259AC` | generated — HSL midpoint of 300/500 |
| `primary-500` | `#4A4380` | given |
| `primary-600` | `#3C3669` | generated — HSL midpoint of 500/700 |
| `primary-700` | `#2E2A52` | given |
| `primary-800` | `#252141` | generated — HSL midpoint of 700/900 |
| `primary-900` | `#1B1830` | given |

Figma's own scale is five stops (100/300/500/700/900), not the ten-stop
50-900 Tailwind convention — there is no `primary-50`. All five given stops
share the same ~247° hue, so 200/400/600/800 are generated by blending in
HSL space between their two real neighbours, keeping every step on-family
rather than drifting through unrelated colours.

are generated the same way as primary's — HSL midpoint between real
neighbours.

### Accent — amber

| Token | Hex | Source |
|---|---|---|
| `accent` | `#E8A33D` | given |

One value, not a scale. **Surface colour only** — button and badge
backgrounds, never text on a light background: Figma's own export states
2.1:1 against a light background, well under the 4.5:1 minimum for normal
text (independently checked here: ~2:1). Dark text (`primary-900`) on an
amber surface passes comfortably (~8:1).

## Spacing

4px base. No custom token needed: Tailwind v4's default `--spacing` is
already `0.25rem` (4px), and Figma's own spacing scale (4, 8, 12, 16, 24,
32, 48, 64, 96) maps exactly onto Tailwind's default numeric scale at those
values.
